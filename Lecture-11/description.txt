Dictionary: allows you to define custom indexes 
the custom indexes are called Key's 
and the data that you store at this keys is calles as values 
- key-value pairs 
- mutable data structure (the values can be updates)
- key: any data type (int,float,string) based on your usecase 
- value: any data 
- for dictonary you use curly brackets {} 
- a dictonary cannot have duplicate keys 
i.e, 
{key-1:value-1,key-1:value-2}
it will not have multiple copies of key-1 instead the value will 
be updated 
synatx: {key-1:value-1,key-2:value-2}
